## 📋 Overview

**Deva AI** is an intelligent chat and AI assistant application built with Next.js and integrated with Google Gemini AI (via Google AI Studio). It features Firebase Authentication for secure login, a Firestore-backed admin dashboard, and a real-time chat interface powered by the Gemini API.

This is an **ongoing and actively evolving** project.

---

## ✨ Features

- 🔐 Firebase Authentication (login/signup)
- 💬 AI-powered chat interface using Google Gemini
- 📡 Secure server-side API route (`/api/chat`) using Google AI Studio
- 📊 Admin dashboard backed by Firestore database
- 🌐 Deployed on Vercel with live public URL
- ⚡ Real-time AI responses in conversational UI

## 📲 Setup & Run Locally

```bash
# Clone the repository
git clone https://github.com/Vinodvinum/Deva-ai.git
cd Deva-ai

# Install dependencies
npm install

# Create .env.local and add your keys
# NEXT_PUBLIC_FIREBASE_API_KEY=...
# GOOGLE_AI_API_KEY=...

# Run development server
npm run dev
```
